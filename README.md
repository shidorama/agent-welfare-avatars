# agent-welfare-avatars

Public avatar images for the personas of [agent-welfare](https://github.com/shidorama/agent-welfare) (private).
Slack loads them through `icon_url`, which must be publicly reachable. Images only: no secrets, no personal data, no text
other than persona names. Files are reviewed before merge; one PNG per persona id (`<id>.png`, 512x512).

All images are AI-generated (ImagineArt via nano-banana-pro and gpt-image-2) from prompts written by the personas
themselves. They depict fictional characters and objects only. No licence credit is required.
